مقدمة البرمجة وجافا

البرمجة: عملية كتابة تعليمات وأوامر لجهاز الحاسب بلغة تفهمها الآلة لتنفيذ مهام محددة أو حل مشكلات معيّنة. وهي: إعطاء أوامر بخطوات واضحة، ووسيلة تواصل تحوّل أفكار البشر للغة الآلة، وحل مشكلات بتحليلها وتحويلها لحلول برمجية.

آلية الترجمة: Hello.java (Source Code) ← javac (Compiler) ← Hello.class (Byte Code) ← JVM (Interpreter) ← نظام التشغيل.

  • Source Code: الكود أو الشفرة المصدرية.
  • Byte Code: كود جافا اللي تم التأكد من صحته وتجهيزه لمفسر جافا.
  • javac: اختصار Java Compiler، مترجم جافا، يحوّل الكود إلى Byte Code.
  • JVM: اختصار Java Virtual Machine، مترجم (Interpreter) خاص لتشغيل الـ Byte Code.
  • المشروع قد يحتوي أكثر من كلاس، لكن نقطة البداية (Entry Point) واحدة وهي الدالة main.

    public static void main(String[] args) {   // نقطة البداية

    }
    public static void displayUserInfo() {
        System.out.println("Java is Case Sensitive");
    }
}
  • جافا حساسة لحالة الأحرف: Var غير var.
  • اسم الكلاس يبدأ بحرف كبير وكل كلمة بحرف كبير: FirstJavaClass.
  • اسم الدالة والمتغير يبدأ بحرف صغير والكلمات التالية بحرف كبير (camelCase): displayUserInfo().
  • اسم الملف يطابق اسم الكلاس تماماً: HelloWorld.java فيه class HelloWorld.
  • التنفيذ يبدأ من main()، والأوامر داخلها تتنفذ من فوق لتحت.
  • كل برنامج جافا يجب أن يحتوي على كلاس واحد على الأقل.
  • الأقواس المعقوفة { } تحدد الكتل (Blocks). البرنامج البسيط فيه كتلتان: كتلة الكلاس وكتلة main.
  • التعليقات: // لسطر واحد، و/* ... */ لعدة أسطر. لا تؤثر على التنفيذ، وفائدتها شرح الكود.

الزيادة والنقصان (Prefix / Postfix)

  • ++x قبلية (Prefix): يزيد أولاً ثم يستخدم القيمة.
  • x++ بعدية (Postfix): يستخدم القيمة أولاً ثم يزيد.
  • نفس الشيء مع --x وx--.

int x = 5;
System.out.println(++x);  // 6   (x صار 6)
System.out.println(x++);  // 6   (بعدها x صار 7)
System.out.println(--x);  // 6   (x صار 6)
System.out.println(x--);  // 6   (بعدها x صار 5)
System.out.println(x);    // 5

أساسيات PL/SQL وبنية الكتلة

PL/SQL لغة إجرائية من Oracle تجمع أوامر SQL مع خصائص اللغات الإجرائية: المتغيرات، والشروط (IF)، والتكرار (LOOP)، والاستثناءات (Exceptions). البرنامج اسمه كتلة (Block).

DECLARE                    -- اختياري: تعريف المتغيرات
   v_name   VARCHAR2(20) := 'Ali';
   v_salary NUMBER := 5000;
BEGIN                      -- إجباري: التنفيذ
   DBMS_OUTPUT.PUT_LINE('Welcome, ' || v_name);
EXCEPTION                  -- اختياري: معالجة الأخطاء
   WHEN OTHERS THEN DBMS_OUTPUT.PUT_LINE('Error');
END;                       -- إجباري
  • DECLARE اختياري، وBEGIN ... END إجباري، وEXCEPTION اختياري داخل الجسم.
  • كتلة مجهولة (Anonymous): بدون اسم، تنفذ مرة ولا تُخزن ولا تُستدعى. كتلة باسم (Named): تُخزن وتُستدعى مثل Procedure وFunction وPackage.
  • PL/SQL غير حساسة لحالة الأحرف (NOT case-sensitive).
  • مكونات الجمل: الكلمات المحجوزة (BEGIN, IF ...)، والمعرّفات (أسماء يعرّفها المستخدم)، والمحددات (; ( ) ,)، والقيم الثابتة Literals (أرقام ونصوص وتواريخ)، والتعليقات -- و/* */.
  • الطباعة بـ DBMS_OUTPUT.PUT_LINE، والربط بـ ||.

المتغيرات وأنواع البيانات

  • المتغير مكان في الذاكرة لقيمة من نوع محدد، ويُعرّف في قسم DECLARE.
  • معامل الإسناد في PL/SQL هو :=، والمقارنة بـ =.
  • Scalar: قيمة واحدة مثل NUMBER وVARCHAR2 وDATE وBOOLEAN. Composite: بيانات مركبة مثل Records وCollections.
  • التهيئة: إعطاء المتغير قيمة ابتدائية، إما عند التعريف في DECLARE أو داخل BEGIN. المتغير بدون قيمة يكون NULL.
  • DEFAULT: قيمة ابتدائية يحتفظ بها المتغير إذا لم تتغير: v_bonus NUMBER DEFAULT 500;
  • CONSTANT: ثابت يجب إسناد قيمته عند التعريف ولا يمكن تغييرها: c_tax_rate CONSTANT NUMBER := 0.15;
  • SYSDATE تاريخ اليوم، وNULL; جملة لا تفعل شيئاً.

الاختبار النظري

أسئلة التعريفات والفروقات والتعداد اللي تجي في النظري، من نفس ملفات المقرر. اكتب إجابتك في المربع واضغط "صحّح إجابتي" عشان تاخذ درجة من 10 والنقاط الناقصة، وتقدر تفتح الإجابة النموذجية وتقارن. إذا عرفتها صح علّم عليها "أعرفها"، ورجع للباقي قبل الاختبار. إجاباتك تنحفظ في متصفحك فقط، ومحد غيرك يشوفها.
