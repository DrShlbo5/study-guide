# مذكرة مراجعة الاختبارات

مذكرة مراجعة لمقررات **جافا (برمج 111)** و **قواعد البيانات PL/SQL** و **PHP**:
ملخصات، حلول تمارين، مسائل للحل، أسئلة نظري مع تصحيح، واختبارات قصيرة.

افتح الموقع من رابط GitHub Pages الخاص بالمستودع.

## هيكل الملفات

```
index.html          الصفحة والمحتوى (الملخصات والحلول)
css/style.css       التنسيق والألوان (فاتح وداكن)
js/data/quiz.js     أسئلة "اختبر نفسك"
js/data/problems.js مسائل PHP
js/data/theory.js   أسئلة النظري (مقالية وصح أو خطأ)
js/quiz.js          منطق الاختبارات
js/problems.js      منطق المسائل
js/grading.js       تصحيح الإجابات المقالية
js/theory.js        منطق قسم النظري
js/main.js          التبويبات
```

لإضافة سؤال، عدّل ملف البيانات المناسب في `js/data/` فقط.

ملاحظة: إجابات الطالب ومسوداته تنحفظ في متصفحه فقط (localStorage).
